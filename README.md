# Embeddable Widget & Lead-Capture Platform

FlyRank Backend Track capstone - a platform where customers create embeddable
widgets (signup forms, CTAs, popovers), embed them on any website with one
`<script>` tag, and collect submissions safely from the open internet:
validated, rate-limited, spam-filtered, geo-enriched, and dashboarded.
